Order confirmations, error messages, hotel bookings, a settings screen
you finally got right, a paragraph you want to quote — screenshots are
the fastest way to keep anything. The problem was always finding them
again. This workflow turns "screenshot it" into a memory that searches
itself.

It's the only workflow here with no deliverable. Retrieval *is* the
output.

## Use this when

- Order confirmations, bookings, and tickets
- A settings screen that finally works, before you change something
- Research clippings and things you want to quote later
- An error message you'll probably see again
- Anything you'd otherwise write down and lose

## Set up once

Nothing, deliberately. That's the workflow's whole claim.

The one thing worth considering: this becomes a diary of your screen, so
turn on [Enhanced Security](/docs/guide/security/) and the whole library
sits encrypted behind Touch ID.

## The loop

1. **Capture without ceremony.** **⌘⇧C** anything worth keeping. Don't
   name it, don't file it — the point of this workflow is that you don't
   have to.

2. **Let the Mac do the filing.** Sealshot OCRs every capture on arrival
   and [generates a title, summary, and Smart
   Keywords](/docs/guide/ai/) from what's visible, all on your Mac.

## Find it again

Weeks later, type what you remember — a vendor, an error code, a
confirmation number, a phrase.
[Search reads inside the images](/docs/guide/library/#search), not just
titles; on Apple Intelligence Macs it
[expands your query](/docs/guide/ai/#smarter-search) to related terms.

![Search matching text inside captures](/manual/library-search.png)

Arrow through the results and tap **Space** for a
[Quick Look](/docs/guide/library/#quick-look) — no editor round-trip. The
date and tag [facets](/docs/guide/library/#sections-and-filters) in the
sidebar narrow things down when search is too broad.

## Later

Curate only what earns it. Star the captures you keep returning to
(**Favorites**), and make a
[collection](/docs/guide/library/#collections-and-favorites) only when a
real project emerges — *Apartment hunt*, *Tax 2026*, *Onboarding notes*.
Everything else stays findable without filing.
