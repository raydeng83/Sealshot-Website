## Set these once

Three settings that change how every capture behaves afterwards. Worth a
minute now.

- **Where captures go.** [Settings →
  Capture](/docs/guide/settings/#capture) decides whether a finished
  capture goes to the **Clipboard**, a **File**, or **Both** (the default),
  and sets the filename format. Clipboard-only skips the editor entirely.
- **Where files land.** The save folder lives in [Settings →
  General](/docs/guide/settings/#general), alongside how long the Trash
  keeps deleted captures.
- **Make the shortcuts yours.** Rebind any command in [Settings →
  Shortcuts](/docs/guide/settings/#shortcuts) — the recorder refuses a
  combination that's already taken, so you can't create a silent conflict.
