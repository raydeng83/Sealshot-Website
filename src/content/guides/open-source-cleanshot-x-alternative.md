CleanShot X set the bar for Mac capture tooling. The reasons people look for an
alternative are usually specific: the licence, the price, or wanting to read the
code that handles their screen.

This guide will cover the features worth comparing rather than counting, what
open source does and does not guarantee about your data, and how the current
Mac capture tools line up.

The side-by-side table is already on the site:
[how Sealshot compares](/compare/). Sealshot itself is free, open source, and
[on GitHub](https://github.com/ldeng83/Sealshot).
